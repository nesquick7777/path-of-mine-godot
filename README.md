# Path of Mine

A 2D roguelike tower defense looter shooter developed in Godot 3 as my final thesis project at the Faculty of Electrical Engineering, Computer Science and Information Technology Osijek (FERIT), University of Osijek.

The player fights through increasingly difficult enemy waves while defending a base. Enemies drop coins, which can be spent on upgrades and spells between waves.

## Gameplay

- Fight waves of enemies with different movement and attack behaviors.
- Defend the base while enemies navigate around obstacles.
- Face enemies with line-of-sight projectile attacks.
- Survive a day and night cycle, including shadows that appear at night and react to light.
- Collect coins and visit the merchant between waves to choose upgrades and spells.
- Use abilities such as an electric orb, a temporary transformation, and time stop.

## Built with

- Godot 3
- GDScript

## Run the project

1. Install Godot 3.
2. Clone or download this repository.
3. In Godot's Project Manager, import the project by selecting `project.godot` in the repository root.
4. Open the project and run it from the editor.
